2. **The keyboard walk (VP10).** A browser test for the main screens:

   - the cursor lands on the heading when a screen opens, and on the first field when a drawer opens;
   - shortcut keys never fire inside a field;
   - focus is visible at 3:1 on every surface, tinted rows included.
   Fix what the walk finds.
3. **Screenshot comparisons in CI (VP15; owner decision D8).**
   - Six screens at two widths (1440 and 390), by day: Today, To-dos, Schedule week, the person's page, Settings AI, and setup's AI step.

   - Build it with Playwright's own screenshot comparison, in a project of its own, on the fixed-clock servers the browser tests already use.
   - A way to update the stored pictures is a documented command.
   - Make sure it runs in CI (`.github/workflows/`). The stored pictures must come from the same rendering as CI's runner, which is Linux like this machine. Check the fonts are bundled, not the system's.
4. **The product file (VP16).**
